Skip ahead rules
After a task is closed, if its answer matches, the case goes straight to a later task and skips the ones in between. Example: after Save Contacts, if Inputs is Satisfied, go to Adv & Chq.
Steps on / off rules
If a case matches the rule, the steps switched OFF are skipped for that case. Other cases run the full chain. Example: if Manager is BB, switch off the steps BB does not need.

Start with General: those points apply to everyone who does the task. Pick a person only to give them different points. Tasks without a Time allowed give no points, and any points conditions set on a task's fields (Add / Edit Tasks) must pass or no points are given. On means finished within the task's Time allowed (for repeating tasks, by the due time). Before means finished at least the time you set earlier than that; After means late but within the time you set; After that is anything later and can be minus. Points go to whoever closes the task, counted in that person's working hours.
